## Summary

I have successfully fixed the `StopIteration` exception that was occurring when using `echo_via_pager()` with generator functions in Click.

### Problem
The issue occurred because `echo_via_pager()` was using `next()` to iterate over generator functions, which would raise a `StopIteration` exception when the generator was exhausted. This was particularly problematic in Python 3.7+ where `StopIteration` inside generators would be converted to `RuntimeError`.

### Solution
I modified the `echo_via_pager` function in `src/click/_termui_impl.py` to properly handle generator functions by:

1. **Using `iter()` with a sentinel**: Instead of calling `next()` directly on the generator, I wrapped it with `iter()` and used a sentinel value (`None`) to detect when iteration is complete
2. **Proper exception handling**: The function now catches `StopIteration` (and `RuntimeError` for Python 3.7+) and handles them gracefully by breaking out of the loop

### Key Changes
- Modified `echo_via_pager` function in `src/click/_termui_impl.py`
