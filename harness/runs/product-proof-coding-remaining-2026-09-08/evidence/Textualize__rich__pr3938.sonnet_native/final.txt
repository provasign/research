The fix: in `Console.print()`, when `crop` is `False` (i.e., soft-wrap enabled), the segments were pushed to the buffer as-is, leaving newline characters embedded inside styled text so the ANSI reset code came *after* the `\n`. Now we route through `Segment.split_and_crop_lines` (with an effectively unbounded length so nothing is cropped, and `pad=False`) which splits the styled text at line boundaries and appends plain, unstyled newline segments — ensuring the reset code is emitted before each newline, matching the non-soft-wrap behavior.
