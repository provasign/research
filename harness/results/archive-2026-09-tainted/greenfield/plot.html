Read before citing

  • n=2–3 trials per cell. The small tier (n=3) and the crossover direction across tiers are a real trend, not noise in sign — but medium/large need more trials before the exact crossover point is a hard number.
  • X-axis is mandated file count, not measured LOC — each scaffold prompt requires an exact file list, and file count is the controlled variable across tiers. Tiny/xlarge tiers (pending) additionally capture real measured LOC per trial.
  • Completeness never broke in either arm at any tested size — the crossover here is a cost signal, not a correctness one. Whether a real completeness gap opens at larger scale, or after a context-compaction gap between phases, is unmeasured.
  • Sonnet/Haiku arms are blocked on Anthropic API credits (account balance empty) — this plot is local-model-only until credits are available.
