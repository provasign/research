This implements the requested feature: when creating a repo interactively and the entered name has no `/` owner prefix, `gh repo create` now fetches the current user's organizations and, if any exist, prompts "Repository owner" with the personal account (default) and orgs listed; selecting an org prefixes the repo name accordingly, while selecting the personal account leaves it unprefixed. If the user belongs to no orgs, the prompt is skipped entirely, matching the issue's spec.
