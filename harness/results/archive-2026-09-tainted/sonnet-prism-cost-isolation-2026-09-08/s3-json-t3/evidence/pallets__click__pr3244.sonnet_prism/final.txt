## Summary

**Root cause:** `CliRunner` replaces `sys.stdout`/`sys.stderr` with `_NamedTextIOWrapper` objects backed by `BytesIOCopy` (a subclass of `io.BytesIO`). When application code calls `subprocess.run(..., stdout=sys.stderr)`, `subprocess` needs a real OS file descriptor via `.fileno()`, but `io.BytesIO` doesn't support that, raising `io.UnsupportedOperation`.

**Fix** (`src/click/testing.py`): Gave `BytesIOCopy` a working `fileno()` that lazily creates a real temporary file (via `tempfile.TemporaryFile()`) the first time a descriptor is requested, seeded with any output already written so far. Also overrode `close()` to clean up that temp file when the buffer is closed. This keeps normal (non-subprocess) usage untouched — no extra file is created unless `fileno()` is actually needed — while making `subprocess.run(stdout=sys.stdout/sys.stderr)` work under `CliRunner`.
