## Summary

**Root cause:** `CliRunner` captured `sys.stdout`/`sys.stderr` using in-memory `io.BytesIO`-backed streams (`BytesIOCopy`). `io.BytesIO` has no real OS file descriptor, so calling `.fileno()` on it (as `subprocess.run(stdout=sys.stderr)` does internally) raised `io.UnsupportedOperation`.

**Fix** (`src/click/testing.py`): Reimplemented `BytesIOCopy` on top of a real `tempfile.TemporaryFile()` instead of `io.BytesIO`, so it exposes a genuine file descriptor via `fileno()`. Writes are still mirrored into the mixed `output` stream as before, and a `getvalue()` method reads the full contents back via `os.pread`/`os.fstat` so `Result.stdout`/`Result.stderr` continue to work unchanged.
