**Describe the bug**

When printing text with a background color and soft wrapping enabled, the background color incorrectly carries over onto the following line. This means an ANSI reset isn't being placed before the newline.

This issue does not occur when `soft_wrap` is set to `False`.

Here is code to reproduce it.

**Note:** To visually reproduce this issue, you must run the code with your prompt at the bottom of the terminal window, forcing the terminal to scroll.

```Python
from rich.console import Console

console = Console()

# Print with soft_wrap enabled. The background color carries over to the next line.
console.print("soft wrap is on", style="blue on white", soft_wrap=True)
console.print("still has background color from previous line")

console.print()

# Print with soft_wrap disabled. The background color does not carry over.
console.print("soft wrap is off", style="blue on white", soft_wrap=False)
console.print("correctly has no color from previous line")
```
