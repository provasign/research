# Issue-prompted benchmark bed (52 tasks) — 2026-10-11

Built because the deep/deephard prompts were specs I wrote (every one quotes the target signatures, most name the file), not human issues. This bed uses the GitHub issue each PR closes, title + body verbatim, as the prompt (`prompt_source: issue` in `tasks/e2e/<id>.json`). Manifest: `results/issue-bed52-manifest.json`.

## Selection

1. `prompt_source == "issue"`: the builder (`build/build_task.py: problem_statement`) follows GitHub's closing-issue link, else a `fixes/closes/resolves #N` in the PR text, and verifies #N is an issue, not a PR. 104 of 203 tasks.
2. Merged on or after 2026-06-01 (past the Sonnet 5.5 training cutoff): 56.
3. Audit (this file): 4 dropped, 52 kept.

## Audit checks run

- Base tree grep for the issue number in test sources (catches "already implemented at base").
- Issue closed_at vs PR mergedAt (a gap of more than 7 days means an earlier fix may exist; each hit inspected by hand).
- Duplicate / backport PRs with no issue of their own.
- Known from the 2026-10-11 pair run: tasks whose merged test contradicts the issue text.

Not detectable automatically: tasks where the gold fix also touches a file the issue never hints at (e.g. gin pr4805). 20 of 52 issues name none of the gold files; that is the discovery work and they stay.
